# Portfolio OBEY Nelci Owen Tunde

Un portfolio professionnel statique présentant mes compétences en développement web, mobile et design.

## 🚀 Déploiement sur GitHub Pages

### Étapes pour déployer :

1. **Créer un repository GitHub**
   - Allez sur GitHub et créez un nouveau repository
   - Nommez-le `username.github.io` (remplacez `username` par votre nom d'utilisateur GitHub)

2. **Uploader les fichiers**
   - Téléchargez tous les fichiers du dossier `static-site`
   - Uploadez-les dans votre repository GitHub

3. **Activer GitHub Pages**
   - Allez dans Settings > Pages
   - Sélectionnez "Deploy from a branch"
   - Choisissez la branche `main` et le dossier `/ (root)`
   - Cliquez sur "Save"

4. **Accéder à votre site**
   - Votre site sera disponible à l'adresse : `https://username.github.io`

## 📝 Personnalisation

Pour personnaliser ce portfolio :

1. **Modifier le contenu** : Éditez `index.html`
2. **Changer les styles** : Modifiez `css/style.css`
3. **Ajouter des images** : Placez vos images dans le dossier `images/`
4. **Mettre à jour les liens** : Changez les URLs dans les sections contact et réseaux sociaux
